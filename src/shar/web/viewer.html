      Backend API keys
      Set provider secrets before starting the server.
      
            
      Get a Gemini key from Google AI Studio, then put it in `.env` or your shell as `GEMINI_API_KEY`. Do not paste provider keys into a public frontend.
      
            
      Minimal Gemini configuration:
      
            
      SHAR_PROVIDER=gemini
SHAR_MODEL=your-accessible-model-id
GEMINI_API_KEY=your-google-ai-studio-key
SHAR_RPM=your-requests-per-minute-limit
SHAR_TPM=your-tokens-per-minute-limit
SHAR_RPD=your-requests-per-day-limit
      
            
      Use the actual limits from Google AI Studio. These local settings do not increase your provider quota.
      
            
      For a remote deployment, also enable app authentication:
      
            
      SHAR_AUTH_MODE=token
SHAR_AUTH_TOKENS={"long-random-token":"owner-1"}
      
            
      Paste that long random token into the Bearer token field on the left.
